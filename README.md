# Constructora Eder Torres

ERP de obra con dos entornos:

- **Escritorio:** multiobra y geocerca, consolidado de asistencia, actas semanales e inventario de EPP.
- **Móvil:** registro de asistencia por geocerca, justificación de retraso, evidencia GPS y entrega de EPP.

## Desarrollo

```bash
npm install
npm run dev
```

La app usa [TanStack Start](https://tanstack.com/start), React y Tailwind.
